# Historical and Deferred Research Programs

This directory preserves compact summaries of substantial earlier research/architecture programs that no longer need to occupy the canonical active implementation tree.

The complete code, tests, discussions and commit history remain available through Git and the historical pull requests.

A historical summary is not an active architecture commitment. It exists to preserve the useful lessons, validated mechanics, negative boundaries and reactivation conditions without forcing current readers to navigate hundreds of superseded implementation files.

## Programs

- [`persistent_runtime_architecture_v0.md`](persistent_runtime_architecture_v0.md) — Research Ledger, Work Threads, scheduler/control, evidence/knowledge integration, hierarchy and indexed materialization.
- [`large_scope_program_v0.md`](large_scope_program_v0.md) — independently weighted Worker-v1 large-scope relevance, same-scope diversity controls and persistent-runtime comparison machinery.
- [`independent_worker_background_v0.md`](independent_worker_background_v0.md) — earlier tiny/independently trained worker direction and why the project moved to fixed learned parameters with shared weights.

## Preservation rule

Historical programs may be reactivated only through a new explicit research question and comparison. Their previous existence is not evidence that the current population-compute organism should inherit their complexity automatically.

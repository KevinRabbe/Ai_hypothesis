# Deferred Research Directions

This directory preserves research directions that may become high-value later but are **not active gates**.

A document here is not an implementation commitment and does not authorize changing a frozen active experiment.

## Activation rule

A deferred direction should become active only when an earlier result makes its causal question decision-relevant and the new experiment can be frozen without contaminating existing confirmation/test boundaries.

## Preserved directions

### Evolutionary organism optimization

[`evolutionary_organism_direction.md`](evolutionary_organism_direction.md)

Training-time population search over candidate shared-weight organisms while runtime population computation remains inside one fixed learned-parameter organism.

The first clean future comparison requires matched total training compute, fixed organism architecture/parameter count, multi-objective phenotype reporting, lineage diversity preservation, and untouched confirmation.

## Current active boundary

The current research program remains Gate 2. Deferred documents must not be used to silently introduce extra architecture variables, learned parameters, training compute, routing complexity, or evaluation exposure into the active Gate-2 protocol.

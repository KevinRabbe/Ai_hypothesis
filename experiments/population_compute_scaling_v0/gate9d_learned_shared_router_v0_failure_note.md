# Gate-9D learned shared router v0 failure note

The v0 router reached perfect bias-gate accuracy but collapsed its contribution
gate to approximately unconditional basis routing. Aggregate local-state
accuracy near 98% was dominated by the negative class and concealed failure on
the selected-versus-unselected basis distinction. Complete XOR execution
therefore remained at chance.

This note preserves the failed development result. The corrective experiment is
a separate hard-negative-balanced v1 and does not rewrite v0.

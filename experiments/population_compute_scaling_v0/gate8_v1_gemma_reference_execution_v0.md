## Pre-inference prompt closure

The complete 10,752-row prompt index is built and hash-bound before the model is instantiated. Every prompt must:

- use the canonical public encoder;
- include exactly the eight frozen demonstrations;
- use the exact Gemma chat template;
- remain ASCII-only;
- contain at most 24,576 input tokens;
- bind its deterministic world ID and oracle answer.

On resume, the entire prompt index is regenerated and compared byte-for-byte before model loading.

## Decoding

```text
batch size       1
do_sample        false
num_beams        1
max_new_tokens   64
attention        SDPA
semantic         greedy_temperature_0
```

No task-specific weight update, sampling, self-consistency, retry, answer repair, constrained decoding, or post-hoc prompt change is admitted.

The decoded generated continuation is trimmed and accepted only when it is exactly one hexadecimal symbol `0..F`. Any other output is an invalid parse and scores incorrect. The raw decoded text and all output token IDs are preserved.

## Transactional recovery

Inference progress is stored in a SQLite database with a primary-key sequence and `synchronous=FULL`. Each completed world is committed independently. `--resume` is admitted only when:

- the exact run fingerprint matches;
- the prompt index regenerates byte-identically;
- existing result rows form a contiguous prefix;
- every stored row matches the corresponding prompt identity.

Resume cannot change a completed answer, skip a world, duplicate a world, or alter decoding.

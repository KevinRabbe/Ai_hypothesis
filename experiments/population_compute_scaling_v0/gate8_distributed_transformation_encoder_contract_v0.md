## Shared topology-neutral aliases

The original per-world node labels remain cryptographically opaque but are deliberately long. The encoder converts them into fixed-width two-character base-36 aliases.

The map is generated by lexicographically sorting the opaque labels and assigning aliases `00..SG`. Because the original labels are independently remapped per world, the resulting alias order is arbitrary with respect to topology, relevant-path position and answer.

The same alias map is used for:

- every population worker observation;
- the complete graph shown to the frozen 1B reference.

Each worker observation still contains only:

```text
population
depth
public root alias
public target alias
root symbol
worker index
one source alias
one target alias
one transform id
```

It contains no other edge, answer, relevance bit or path position.

## Canonical complete-graph format

Every graph starts with one query line:

```text
Q|P=<population>|D=<depth>|R=<root>|Z=<target>|S=<symbol>
```

It is followed by exactly `population` edge lines in frozen worker-index order:

```text
<source>><target>:<transform-id>
```

The encoder does not sort edges by topology. It preserves the generator's randomized interleaving of relevant and distractor workers.

## Pre-tokenization budget

The protocol allows at most 24,576 reference input tokens.

Before binding the exact tokenizer, this stage freezes:

```text
canonical ASCII content limit       = 20,000 bytes
template + special-token reserve    = 4,576 tokens
combined admission envelope         = 24,576
```

All 21 contract conditions, including the complete 1,024-edge/depth-128 graph and all eight demonstrations, must fit below the 20,000-byte content limit without truncation.

This is intentionally not labeled an exact tokenizer proof. The encoder records:

```text
exact_tokenizer_bound_proven = false
```

A later admission stage must bind the exact immutable Gemma tokenizer revision, apply its real chat template, tokenize every frozen condition, and prove the final count is at most 24,576 before any 1B model inference is allowed.
